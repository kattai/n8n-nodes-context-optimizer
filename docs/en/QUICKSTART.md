# Context Saver 1.0 quick start

1. Add `Context Saver`, choose `Agent Model`, then connect `Chat Model -> Context Saver -> AI Agent`.
2. Select `Save Tokens`, `Balanced`, and keep adaptive protection enabled.
3. Add `Savings Report / Current Execution` after the agent path.
4. For large tool results, use `Maximum Savings` with `Exact Lookup` connected to the same Agent and matching storage/isolation settings.
5. For multi-agent workflows, pass `Agent Handoff` instead of the full transcript.

Typical eligible reductions: Quality First 15–35%, Balanced 35–60%, Maximum Savings 60–85%. These are benchmark ranges, not billing guarantees. Risky or ambiguous calls automatically retain more context.
